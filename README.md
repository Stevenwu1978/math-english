# Math 英文數學

4 年級 enVision Mathematics（Volume 1）雙語互動練習網站：影片、單字卡（英文、中文、發音）、配對遊戲、步驟拆解應用題、小測驗與成績紀錄。

- 課程內容在 `data.js`
- 進度存在瀏覽器（localStorage），每個孩子請固定使用同一台裝置與瀏覽器

## 登入與權限

- 第一次打開會要求設定家長密碼。家長可新增孩子、設定孩子 PIN、開放或關閉單元、查看與重設成績。
- 孩子點自己的名字並輸入 PIN 登入，只會看到自己的進度和錯題本。關閉瀏覽器分頁後需重新登入。
- 這是瀏覽器端的使用限制，用來分開孩子的紀錄、讓家長控管；網站內容本身是公開的。忘記家長密碼只能清除這個網站的瀏覽器資料。
